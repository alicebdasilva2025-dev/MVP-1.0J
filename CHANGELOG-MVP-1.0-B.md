# MVP-1.0-B — Lista de exercícios recolhida

## Alteração B
- As listas de exercícios dos treinos começam recolhidas para reduzir a poluição visual na tela de Treinos.
- Ao clicar no nome do treino, a pessoa pode exibir ou recolher a lista de exercícios daquele treino.
- O controle mostra uma indicação visual de expandir/recolher e a quantidade de exercícios cadastrados.
- Os botões de editar/excluir treino, concluir treino, criar lembrete e adicionar exercício foram preservados.
- A alteração vale para treinos planejados e para o histórico de treinos concluídos.
