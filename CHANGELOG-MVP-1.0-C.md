# MVP-1.0-C — Tipos de treino e análise semanal

- Adicionadas sugestões clicáveis para o campo Tipo: Força, Cardio, Flexibilidade, Mobilidade, Resistência muscular, HIIT, Funcional, Equilíbrio, Recuperação ativa, Esporte, Misto e Outro (digitar).
- Mantido o campo editável para tipos personalizados.
- Adicionada seção “Análise de evolução semanal” com visualizações por tipo de treino, tempo acumulado, repetições e carga acumulada estimada para treinos de força.
- A análise usa os dados registrados nos treinos da semana selecionada; carga acumulada é calculada como carga realizada × repetições realizadas e depende de os registros estarem preenchidos.
